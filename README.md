# Edge-based Room Occupancy Detection

This module handles integration of the mmWave sensor and mini microphone module on a Raspberry Pi for real-time room occupancy detection.

## Features
- mmWave sensor integration
- Microphone module integration
- Local data processing
- Utilities for logging and data formatting

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the main script:
   ```bash
   python src/main.py
   ```

## Folder Structure
- `src/` : Source code for sensor integration
- `tests/` : Unit tests
- `docs/` : Documentation
- `images/` : Diagrams and wiring images
- `data/audio/` : Recorded audio clips (WAV, for YAMNet)
- `data/images/` : Captured webcam images (JPG/PNG, for YOLO)
- `data/mmwave/` : mmWave sensor logs (CSV, for occupancy detection)
